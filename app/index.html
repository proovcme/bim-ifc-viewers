Конвертация IFC → XKT
github.com/xeokit/xeokit-convert · один раз локально
1 Node.js 18

Через nvm (рекомендуется) или с nodejs.org.

nvm install 18 && nvm use 18
2 Клонировать конвертер
git clone https://github.com/xeokit/xeokit-convert.git
cd xeokit-convert && npm install && cd ..
3 Конвертация
NODE_OPTIONS="--max-old-space-size=8192" \
node ./xeokit-convert/convert2xkt.js \
  -s "model.ifc" \
  -o "model.xkt" -l
1 Node.js 18

Скачайте с nodejs.org (LTS 18.x) или winget:

winget install OpenJS.NodeJS.LTS
2 Клонировать конвертер
git clone https://github.com/xeokit/xeokit-convert.git
cd xeokit-convert && npm install && cd ..
3 Конвертация — PowerShell
$env:NODE_OPTIONS="--max-old-space-size=8192"
node ./xeokit-convert/convert2xkt.js -s "model.ifc" -o "model.xkt" -l

cmd.exe:

set NODE_OPTIONS=--max-old-space-size=8192
node ./xeokit-convert/convert2xkt.js -s "model.ifc" -o "model.xkt" -l
Флаг -l — прогресс в консоли. Для файлов >100 МБ NODE_OPTIONS обязателен. Время: 2–15 мин.
На сервере: положите файл по пути
./data/projects/ovc/models/ИМЯ/geometry.xkt
— вьювер подхватит через панель Models.

Локально: кнопка «Добавить XKT» — файл читается прямо из браузера.
