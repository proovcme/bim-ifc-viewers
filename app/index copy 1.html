Конвертация IFC → XKT

Вьювер работает только с форматом .xkt. Конвертация делается один раз на компьютере перед загрузкой на сайт.

1. Подготовьте окружение

nvm install 18 && nvm use 18
git clone https://github.com/xeokit/xeokit-convert.git
cd xeokit-convert && npm install && cd ..

2. Запустите конвертацию

NODE_OPTIONS="--max-old-space-size=8192" \
node ./xeokit-convert/convert2xkt.js \
  -s "model.ifc" \
  -o "model.xkt" -l

📝 Флаг -l покажет прогресс. Для файлов >100 МБ обязательно используйте NODE_OPTIONS.
